제어반 배선·통신 통합 · 2026-11-02

접점 배선을 전원·통신 공용 케이블로 바꾼 제어반 구조

로크웰 오토메이션의 EtherNet/IP 인캐비닛 구성은 제어반의 푸시버튼, 접촉기와 과부하계전기를 개별 접점선 대신 평면 케이블 한 가닥에 연결합니다. 1834-AENTR 게이트웨이가 공장 EtherNet/IP와 제어반 내부 10BASE-T1S 구간을 연결하고, 1486-CBL 케이블이 통신과 두 종류의 전원을 각 장치에 분배합니다.

기존 배선과 무엇이 달라졌나

기존 제어반은 장치마다 입력선, 출력선과 공통선을 단자대와 입출력 모듈까지 각각 연결합니다. 인캐비닛 구성은 장치 가까이에서 접점신호를 통신 데이터로 바꾸고, 여러 장치를 평면 케이블에 분기 연결합니다.

그림을 먼저 보면 기존 구조는 장치별 선이 중앙 단자대와 I/O 모듈로 모입니다. 개선 구조는 게이트웨이 뒤 평면 케이블에서 장치를 바로 분기합니다.
공개 케이블 길이최대 25m
공개 연결 수최대 40노드
내부 통신10BASE-T1S

한 케이블에서 무엇이 흐르나

1486-CBL에는 통신선과 두 종류의 전원선이 들어갑니다. NP 전원은 장치 통신 인터페이스를 가동합니다. SP 전원은 접촉기 코일처럼 전력이 더 필요한 부하에 사용합니다. 장치 위치를 정하는 선도 케이블에 포함됩니다.

장점과 한계

장점

  • 장치별 접점선과 단자 수를 줄여 조립시간과 도면 복잡도를 낮춥니다.
  • 접점의 켜짐·꺼짐 외에 장치 식별정보, 운전상태와 고장정보를 제어기에서 읽을 수 있습니다.
  • 장치 가까이에서 신호를 통신 데이터로 바꾸므로 중앙 I/O 채널을 줄일 수 있습니다.

한계

  • 한 구간은 공개 사양의 25m와 40노드 범위 안에서 설계해야 합니다.
  • 평면 케이블이나 게이트웨이 고장이 여러 장치에 미치는 영향을 회로별로 계산해야 합니다.
  • NP·SP 전원용량과 접촉기 코일 기동전류를 장치 구성에 맞춰 확인해야 합니다.

현장에서는 어디를 측정하나

시험은 케이블을 연결한 뒤 통신 여부만 보는 것으로 끝내지 않습니다. 게이트웨이에서 공장망 연결시간을 기록하고, 케이블 끝단에서는 통신 오류와 전압강하를 측정합니다. 접촉기 분기점에서는 코일 동작 때 SP 전압과 장치 응답시간을 확인합니다.

  1. 게이트웨이 시험: 제어기와 1834-AENTR의 전원을 켠 뒤 장치 인식시간을 기록합니다. 공장 EtherNet/IP 케이블을 10초간 분리하고 고장 검출시간과 재연결시간을 각각 20회 측정합니다.
  2. 케이블 끝단 시험: 1486-CBL 시작점과 끝점의 NP·SP 전압을 무부하와 최대 부하에서 측정합니다. 케이블 길이와 장치 수를 함께 기록해 전압강하 기준을 정합니다.
  3. 접촉기 시험: 접촉기 코일을 100회 켜고 끕니다. 제어기 명령 시각부터 보조접점 상태가 바뀌는 시각까지의 응답시간과 실패 횟수를 기록합니다.

용어 설명
EtherNet/IP (EtherNet Industrial Protocol)표준 Ethernet 위에서 제어기와 산업장치의 입출력·진단 데이터를 전달하는 산업통신 규격입니다.
10BASE-T1S (10 Megabit Baseband Single Pair Short Reach)한 쌍의 구리선으로 여러 장치를 짧은 구간에 연결하는 10Mbps Ethernet 방식입니다.
I/O (Input/Output)센서 신호를 읽고 접촉기·밸브 등에 명령을 내리는 제어기의 입출력 기능입니다.
NP 전원 (Network Power)푸시버튼과 접촉기 통신 인터페이스를 가동하는 네트워크 장치 전원입니다.
SP 전원 (Switched Power)접촉기 코일처럼 켜고 끄는 부하에 공급하는 전원입니다.
멀티드롭한 통신선에 여러 장치를 중간 분기 방식으로 연결하는 배선 구조입니다.
