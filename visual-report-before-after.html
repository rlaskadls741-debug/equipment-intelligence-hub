현재 방식 · 글 중심

EtherCAT과 TSN을 한 FPGA에서 처리하는 산업용 통신 구조

마이크로칩은 10월 29일 PolarFire FPGA와 SoC용 산업통신 구성을 공개했습니다. Beckhoff EtherCAT IP는 장치 통신을 처리하고, 마이크로칩 TSN IP는 1Gbps Ethernet에서 제어패킷의 전송시각과 우선순위를 관리합니다.

현재 독자가 해야 하는 일
아래 문장을 읽은 뒤 EtherCAT 장치, FPGA 논리영역, 프로세서와 TSN 상위망의 위치를 머릿속으로 다시 배치해야 합니다.

기술 구조와 작동 과정

EtherCAT MainDevice가 전송한 프레임이 장비의 Ethernet 포트로 들어옵니다. PolarFire FPGA에 구현된 EtherCAT 장치 제어기가 프레임을 통과시키면서 해당 장비의 출력데이터를 읽고 입력데이터를 기록합니다.

FPGA 논리영역은 EtherCAT 프레임 처리와 모터제어, 센서 전처리 또는 영상입력 회로를 병렬로 실행합니다. PolarFire SoC의 프로세서는 EtherCAT 공정데이터를 장비상태, 알람과 생산정보로 변환합니다.

Linux 기반 TSN 소프트웨어가 이 데이터를 상위 Ethernet 망으로 전달합니다. PTP는 TSN 장치와 스위치의 시계를 맞추고, 시간인식 스케줄러는 제어패킷이 전송될 시간구간을 예약합니다.

기존 방식과 달라진 점

  • 기존 장비는 EtherCAT 장치 제어기, 일반 프로세서와 상위망 통신칩을 각각 배치했습니다.
  • 새 구성은 EtherCAT 장치 제어기와 TSN 종단기능을 PolarFire 계열의 프로그램 가능 논리와 프로세서에 함께 배치합니다.
  • 통신회로를 FPGA에서 병렬로 처리하므로 CPU 응용프로그램의 실행시간 변화와 통신 프레임 처리의 영향을 분리할 수 있습니다.

사전검증 순서

  1. EtherCAT 장치와 TSN 상위망을 평가보드에 연결하고 통신주기와 시계오차를 기록합니다.
  2. 영상·로그 트래픽을 증가시키면서 EtherCAT 주기지연과 TSN 제어패킷 지연을 측정합니다.
  3. EtherCAT 또는 TSN 케이블을 분리하고 고장 검출시간과 복구시간을 측정합니다.
수정 후 · 기존 대비 시각화

EtherCAT과 TSN을 한 FPGA에서 처리하는 산업용 통신 구조

마이크로칩은 10월 29일 PolarFire FPGA와 SoC용 산업통신 구성을 공개했습니다. Beckhoff EtherCAT IP는 장치 통신을 처리하고, 마이크로칩 TSN IP는 1Gbps Ethernet에서 제어패킷의 전송시각과 우선순위를 관리합니다.

기존 방식과 새 구조 비교

기존 대비 달라진 점 EtherCAT 장치 통신과 TSN 상위통신을 서로 다른 칩에서 처리하던 구성을 PolarFire SoC의 FPGA 논리영역과 프로세서 안에 함께 배치합니다.

데이터가 이동하는 순서

사전검증 장비와 측정 위치

  1. EtherCAT 구간
    1ms 주기로 8시간 운전하며 실제 주기, 최대 지터와 누락 프레임을 기록합니다.
  2. 평가보드 내부
    영상·센서 전처리 부하를 단계별로 높이고 EtherCAT 프레임 처리시간과 프로세서 사용률을 함께 기록합니다.
  3. TSN 구간
    일반 영상 트래픽을 증가시킨 뒤 제어패킷 지연, PTP 시계오차, 케이블 분리 후 복구시간을 측정합니다.
