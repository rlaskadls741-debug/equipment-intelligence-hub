DEMOKIT · PC 제어 프로그램 분석 Tool

사용 설명서

전체 운전 흐름에서 시작해 세부 도식과 원문 코드 근거까지 따라가는 방법을 정리했습니다.

Tool 열기빠른 시작
목차빠른 시작화면 구성흐름도 보기확대·이동원문·해설 보기검색·사전기호·색상·노란 표시읽을 때 주의할 점

빠른 시작

처음에는 전체 흐름도에서 큰 순서를 보고, 관심 있는 단계의 상자를 눌러 원문 근거를 확인하면 됩니다.

  1. 왼쪽 전체 흐름도를 눌러 프로그램 시작부터 정지까지의 큰 흐름을 봅니다.
  2. 도식의 상자를 눌러 선택 동작의 설명과 연결된 코드 근거를 엽니다.
  3. 더 자세히 보려면 상단의 상세 흐름도 열기 또는 왼쪽 기능별 목록에서 관련 도식을 고릅니다.
  4. 오른쪽 근거 창에서 코드 줄, 동작 해설, 함수의 선언·호출·구현을 확인합니다.
상자는 “어떤 단계가 실행되는가”를 보여주고, 근거 창은 “그 단계가 코드에서 어떻게 연결되는가”를 확인하는 곳입니다.

화면 구성

상단Tool 제목과 전체 흐름도 바로가기, 변경 이력을 확인합니다.
왼쪽 탐색‘주요 화면’ 바로 아래의 ‘사용 설명서 보기’로 이 설명서를 엽니다. 그 아래에서 전체 흐름도, 원문 코드·해설, 코드 사전, 검색 결과, 함수 호출 관계, 하드웨어 이해를 고릅니다. 기능별 상세 흐름도도 이곳에서 선택합니다.
가운데 작업 영역선택한 흐름도와 설명을 봅니다. 도식 안의 상자는 눌러 관련 근거를 열 수 있습니다.
오른쪽 근거 창선택한 단계의 요약, 코드와 줄별 해설, 함수 연결, IO·축 번호 정의 등을 확인합니다. 닫기로 접습니다.

전체 흐름도와 상세 흐름도

  • 전체 흐름도: 장치 준비, 입력 감시, 원점복귀, 자동 운전, 수동 운전, 정지·오류까지 상위 순서를 봅니다.
  • 기능별 상세 흐름도: EtherCAT, 센서 감시, 서보·모터, 자동 운전, 실린더·진공, 인버터·컨베이어 등 기능별 절차를 자세히 봅니다.
  • 도식 위의 이전 도식과 다음 도식으로 같은 묶음의 앞뒤 항목을 이동합니다.
  • 상자를 누르면 연결된 코드 근거가 열립니다. 도식에서 연결된 호출 관계를 따라가며 어느 함수로 이어지는지 확인할 수 있습니다.

도식 크기와 위치 조절

조작방법추천 상황
배율 선택도식 위의 확대 비율 메뉴에서 폭 맞춤, 전체 맞춤, 75·100·125·150% 중 선택처음 열었을 때 전체를 보거나 글자를 크게 볼 때
세밀한 확대·축소Ctrl을 누른 채 마우스 휠을 위·아래로 움직임특정 구간을 자세히 읽을 때
위치 이동도식 위에서 마우스 왼쪽 버튼을 누른 채 끌기확대한 뒤 화면 밖으로 간 부분을 찾을 때
벡터 그림 저장벡터 그림 저장 버튼 선택도식을 별도 이미지로 보관하거나 문서에 넣을 때
도식이 너무 크거나 작으면 먼저 폭 맞춤 또는 전체 맞춤을 선택한 다음, Ctrl+휠로 세밀하게 조절하세요. 위치가 어긋나면 도식 안에서 드래그해 다시 맞추면 됩니다.

원문 코드와 해설 보기

  • 흐름도 상자나 연결된 근거 버튼을 선택하면 해당 동작의 근거 창이 열립니다.
  • 줄별 해설 보기를 켜면 코드 줄 아래에 해당 줄의 역할이나 전달값 설명이 표시됩니다. 끄면 원문 코드 중심으로 볼 수 있습니다.
  • 원문에서 보기를 누르면 해당 파일·행으로 이동합니다. 전체 코드를 직접 찾을 때는 왼쪽 원문 코드·해설 화면을 사용합니다.
  • 함수의 선언·호출·구현을 펼치면 함수가 선언된 곳, 호출하는 곳, 실제 구현된 곳을 구분해서 볼 수 있습니다.
  • IO·축·모듈 번호 정의가 연결된 단계에는 관련 토큰 버튼이 보일 수 있습니다. 버튼을 누르면 해당 번호 정의나 상태 변수 선언 위치로 이동합니다.

검색과 코드 사전

  • 왼쪽 검색창에 센서 번호, IO 이름, 함수명, 상태 변수 등을 입력합니다. 예: DI12, InMotion, RESET.
  • 검색 결과를 선택하면 관련 단계나 원문 위치로 이동합니다. 검색어를 지우면 전체 탐색 화면으로 돌아갈 수 있습니다.
  • 코드 사전에서는 함수·상수·상태 변수를 찾아 역할과 연결 위치를 확인합니다.
  • 하드웨어 이해에서는 모듈, 센서, 컨베이어, 입출력 관계를 코드 흐름과 함께 확인합니다.
함수명이나 상수명이 기억나지 않으면 동작 이름이나 센서 번호처럼 알고 있는 단어부터 검색해 보세요.

기호·색상과 노란색 코드 표시

  • 흐름도 기호와 분기 표시의 설명은 00 · 기호와 색상 안내에서 확인합니다. 색상은 읽기 편하게 구분한 보조 표현이며, 색만으로 실행 순서를 판단하지 않습니다.
  • 코드의 파랑·보라 등 글자색은 키워드와 API 이름을 구분하는 문법 표시입니다.
  • 노란색 표시는 코드 토큰 자체의 색이 아니라, 흐름도나 근거에서 이동해 온 선택 코드 줄을 가리키는 위치 강조입니다. 해당 줄 근거를 선택하지 않고 원문 화면을 직접 열면 노란 강조가 없을 수 있습니다. 노란 강조가 안 보여도 코드가 빠진 것은 아닙니다.
  • 일부 단계에는 연결된 번호 정의나 변수 선언이 없어서 토큰 버튼이 표시되지 않을 수 있습니다. 모든 단계에 같은 토큰 목록이 나오는 구조는 아닙니다.

읽을 때 주의할 점

  • 코드에서 출력·이동 명령을 호출했다는 사실만으로 실제 장치가 움직였다고 단정하지 않습니다. 완료 입력, 센서 상태, 오류 및 인터록 조건을 함께 확인합니다.
  • 도식은 코드와 설명을 연결해 읽기 쉽게 만든 자료입니다. 판단이 필요한 경우 원문 행과 연결된 상태 변수·IO 정의를 함께 확인합니다.
  • 화면이 좁을 때는 사이드바와 근거 창이 가운데 도식을 가릴 수 있습니다. 근거 창을 닫거나 브라우저 창을 넓힌 뒤 배율을 다시 맞추면 편하게 볼 수 있습니다.
