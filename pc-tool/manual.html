사용 설명서

운전 흐름과 원문 코드 근거를 확인하고, 우상단 변환 체크리스트에 전환 작업을 기록하는 방법을 정리했습니다.

Tool 열기빠른 시작
목차빠른 시작화면 구성우상단 변환 체크리스트흐름도 보기확대·이동원문·해설 보기검색·사전기호·색상·노란 표시읽을 때 주의할 점

빠른 시작

  1. 전체 흐름도에서 궁금한 단계를 누릅니다. 설명·실행 코드·관련 함수 선언이 함께 나옵니다.
  2. 파일 전체를 읽으려면 코드 옆의 원문 보기를 누릅니다. 선택 범위가 바로 강조됩니다.
  3. 흐름도로 돌아가기를 누르면 선택 단계와 확대 위치로 돌아옵니다.

화면 구성

상단·우상단우상단 고정 영역의 Ajin > WMX3 변환 체크리스트에서 전환 작업 기록을 엽니다. Tool 제목 아래에는 전체 흐름도 바로가기, 변경 이력과 검증 이력이 있습니다.
왼쪽 탐색‘주요 화면’ 바로 아래의 ‘사용 설명서 보기’로 이 설명서를 엽니다. 그 아래에서 전체 흐름도, 원문 코드·해설, 코드 사전, 검색 결과, 함수 호출 관계, 하드웨어 이해를 고릅니다. 기능별 상세 흐름도도 이곳에서 선택합니다.
가운데 작업 영역선택한 흐름도와 설명을 봅니다. 도식 안의 상자는 눌러 관련 근거를 열 수 있습니다.
오른쪽 근거 창선택 단계의 설명, 실행 코드와 함수 선언을 바로 봅니다. 변수·문서는 추가 근거·변수·문서에 있습니다. 좁은 화면에서는 흐름도 아래에 이어서 표시합니다.

우상단 · Ajin > WMX3 변환 체크리스트

아진에서 WMX3로 전환할 때 확인할 60개 항목을 보고, 현재 상태와 확인 결과를 기록하는 화면입니다.

여는 위치: Tool 화면 맨 위 오른쪽의 Ajin > WMX3 변환 체크리스트 버튼을 누릅니다. 같은 화면 안에 체크리스트가 열립니다. 흐름도로 돌아가기 ×를 누르면 기존 흐름도로 복귀합니다.

항목 확인과 기록

  1. 확인값 · 결과 · 다음 작업 보기를 펼쳐 각 항목에서 확인한 값, 현재 결론과 이어서 할 작업을 읽습니다. 문서·코드 검토 상태와 출처도 함께 남아 있습니다. 근거 모두 펼치기로 전체 항목의 근거를 한 번에 열 수 있습니다.
  2. 각 항목의 현재 상태에서 확인 완료, 부분 확인, 미확인을 선택합니다. 항목 색상과 상단 현황 숫자가 함께 바뀝니다.
  3. 작업 메모에는 60개 항목 모두 확인값·결과·다음 작업이 미리 작성되어 있습니다. 실제 설정값이나 시험 결과가 나오면 해당 문장을 수정하거나 아래에 추가합니다. 기존에 작성한 메모는 유지됩니다. 이전 저장값에서 비어 있던 메모만 채워집니다.
  4. 변경 즉시 자동 저장됩니다. 상단의 자동 저장됨 표시를 확인합니다. 지금 저장으로도 현재 기록을 저장할 수 있습니다.

항목 / 확인 근거C01~C60의 확인값·결과·다음 작업과 문서·코드 출처를 확인합니다.
현재 상태내가 진행한 작업에 맞춰 세 가지 상태 중 하나를 선택합니다.
작업 메모 · 수정 가능미리 작성된 확인값·결과·다음 작업을 바탕으로 실제 설정값, 시험 결과, 업체 답변과 진행 사항을 수정·추가합니다.

검색·필터와 상태별 색상

  • 항목 검색에 항목 번호나 키워드를 입력합니다. 예: C05, PDO, 전자기어. 입력한 메모도 검색 대상입니다.
  • 분류·현재 상태로 범위를 좁힙니다. 상단의 상태별 현황 숫자를 눌러도 해당 상태만 볼 수 있으며, 같은 현황을 다시 누르면 상태 필터가 해제됩니다.
  • 이전 문의 4개 주제를 선택하면 전자기어비·1SN 원점/리밋·PM2Q A/B접점·인버터 PDO 관련 항목을 모아 봅니다.
  • 상태별 기본 색상 조정을 펼치면 확인 완료·부분 확인·미확인의 색상을 변경할 수 있습니다. 변경한 색상은 같은 상태의 항목에 함께 적용되고 자동 저장됩니다.

저장 범위와 백업 파일

상태·메모·상태별 기본 색상은 현재 PC의 현재 브라우저에 저장됩니다. 새로고침하거나 같은 브라우저에서 Tool을 다시 열면 저장값을 불러옵니다. 다른 PC·브라우저와 자동 동기화되지는 않습니다.

  • 저장 파일 내보내기: 현재 기록을 JSON 파일로 내려받습니다. 다른 PC로 옮기거나 브라우저 데이터를 지우기 전에 보관할 수 있습니다.
  • 저장 파일 불러오기: 이 체크리스트에서 내보낸 JSON 파일을 선택한 다음, 확인 창에서 불러오기 적용을 누릅니다. 해당 항목의 상태·메모와 상태별 기본 색상이 파일의 값으로 바뀝니다.
  • 최초 확인 근거는 사용자가 편집하는 진행 기록과 별도로 남습니다. 상태·메모를 바꾸거나 백업을 불러와도 최초 검토 내용은 유지됩니다.
검토 기준: 현재 사용 버전과 향후 전환 대상은 WMX3 3.6입니다. 5번 항목에서 사용 버전과 라이선스 확인 내용을 볼 수 있습니다. 최초 검토의 초록색은 문서·코드 확인을 뜻하며, 구현·컴파일·실물 시험 완료 여부는 근거와 작업 기록을 함께 확인해야 합니다.

전체 흐름도와 상세 흐름도

  • 전체 흐름도: 장치 준비, 입력 감시, 원점복귀, 자동 운전, 수동 운전, 정지·오류까지 상위 순서를 봅니다.
  • 기능별 상세 흐름도: EtherCAT, 센서 감시, 서보·모터, 자동 운전, 실린더·진공, 인버터·컨베이어 등 기능별 절차를 자세히 봅니다.
  • 도식 위의 이전 도식과 다음 도식으로 같은 묶음의 앞뒤 항목을 이동합니다.
  • 상자를 누르면 연결된 코드 근거가 열립니다. 도식에서 연결된 호출 관계를 따라가며 어느 함수로 이어지는지 확인할 수 있습니다.

원문 코드와 해설 보기

행/범위 한 칸에 500을 입력하면 한 줄, 500-519 또는 500+20을 입력하면 500~519행을 강조합니다. 파일 전체는 그대로 표시됩니다. 이동 버튼이나 Enter로 현재 원문 화면 안에서 이동합니다.
  • 단계 선택 창에는 실행 코드와 함수 선언을 기본으로 표시합니다. 긴 범위는 앞 12행을 보여주며, 원문 보기에서 전체 범위를 확인합니다.
  • 선언 옆의 파일·행 버튼으로 헤더를 바로 엽니다. 호출 관계에서는 호출 위치와 함수 구현을 확인합니다.
  • 원문 화면의 줄별 해설 보기로 줄마다 붙는 설명을 켜거나 끕니다. 추가 근거·변수·문서에는 다른 코드 범위, 번호 정의와 문서 출처가 있습니다.
구분의미
선언함수 이름과 입력·반환 형식입니다. 선언만으로 실행되지는 않습니다.
호출·이벤트 연결함수를 실행하는 위치나 계기입니다. MFC 내부 호출은 제공 소스에 없을 수 있습니다.
구현함수 안에서 조건 검사·명령·반환 등을 처리하는 코드입니다.

검색과 코드 사전

  • 왼쪽 검색창에 센서 번호, IO 이름, 함수명, 상태 변수 등을 입력합니다. 예: DI12, InMotion, RESET.
  • 검색 결과를 선택하면 관련 단계나 원문 위치로 이동합니다. 검색어를 지우면 전체 탐색 화면으로 돌아갈 수 있습니다.
  • 코드 사전에서는 함수·상수·상태 변수를 찾아 역할과 연결 위치를 확인합니다.
  • 하드웨어 이해에서는 모듈, 센서, 컨베이어, 입출력 관계를 코드 흐름과 함께 확인합니다.
함수명이나 상수명이 기억나지 않으면 동작 이름이나 센서 번호처럼 알고 있는 단어부터 검색해 보세요.

기호·색상과 노란색 코드 표시

  • 흐름도 기호와 분기 표시의 설명은 00 · 기호와 색상 안내에서 확인합니다. 색상은 읽기 편하게 구분한 보조 표현이며, 색만으로 실행 순서를 판단하지 않습니다.
  • 코드의 파랑·보라 등 글자색은 키워드와 API 이름을 구분하는 문법 표시입니다.
  • 노란 배경과 점선 밑줄이 있는 단어·연산자는 클릭해서 사전 설명을 열 수 있는 코드 항목입니다. 왼쪽 메뉴에서 원문을 직접 열거나 흐름도에서 이동해도 같은 방식으로 표시합니다.
  • 선택한 행의 배경과 왼쪽 선은 현재 이동한 코드 위치·범위를 뜻합니다. ‘행/범위’ 입력칸으로 범위를 바꿀 수 있으며, 사전을 여는 단어 표시는 이 선택 범위와 별개입니다.
  • 일부 단계에는 연결된 번호 정의나 변수 선언이 없어서 토큰 버튼이 표시되지 않을 수 있습니다. 모든 단계에 같은 토큰 목록이 나오는 구조는 아닙니다.

읽을 때 주의할 점

  • 코드에서 출력·이동 명령을 호출했다는 사실만으로 실제 장치가 움직였다고 단정하지 않습니다. 완료 입력, 센서 상태, 오류 및 인터록 조건을 함께 확인합니다.
  • 도식은 코드와 설명을 연결해 읽기 쉽게 만든 자료입니다. 판단이 필요한 경우 원문 행과 연결된 상태 변수·IO 정의를 함께 확인합니다.
  • 넓은 화면에서는 흐름도와 단계 설명을 나란히 봅니다. 좁은 화면에서는 설명이 아래에 이어집니다.
