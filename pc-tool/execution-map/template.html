전체 실행 지도

작업들은 서로 다른 계기로 시작합니다. 관심 있는 상자를 선택하세요.

코드 기반 학습 지도 · 실제 실행 계측 화면이 아닙니다.

그림을 따라 읽는 방법

  1. 전체 지도에서 시작점 하나를 고릅니다. 프로그램 전체가 한 줄로 실행되는 구조는 아닙니다.
  2. 다음 단계로 화살표를 따라갑니다. 조건에서는 직접 예 / 아니오를 선택합니다. 변수 값을 실행하거나 계산하지 않습니다.
  3. 파란 호출 상자에서 함수 안으로 들어갑니다. 위쪽에는 호출 경로가 남고, 호출 위치로 복귀하면 원래 상자로 돌아옵니다.
  4. 초록 상자의 스레드는 별도 작업입니다. 따라 들어가 보는 동안에도 실제 프로그램에서는 호출자와 병행할 수 있습니다.
  5. 오른쪽에서 원문과 해설을 확인합니다. 선언 보기는 위치 확인용이며 실행 단계가 아닙니다.

214개 함수의 if·else·while·for·do·return 구조를 원문에서 추출했습니다. switch 및 복잡한 내부 구문은 원문 묶음으로 표시합니다. 매크로·SDK·MFC 내부 동작은 이 도식에서 실행하지 않습니다. 반복 조건, 분기, 반환값의 실제 결과는 설비 상태와 입력에 따라 달라집니다.

DI0 START 조건 · 코드와 실제 구성 구분

이 설비는 기존 IO가 구성되어 있고, 사용자는 AUTO 탭 Run으로 자동운전을 시작합니다. Run은 MFC 클릭 이벤트이며 DI0 값을 직접 쓰는 동작이 아닙니다.

원문에는 _START_SWITCH=0 및 m_bInput[0] 조건에 따라 OnAutoRun → OnAutoRunUpdate → OnButtonAutoRun으로 이어지는 코드가 있습니다.

확인 범위
DI0의 실제 신호원은 현재 확인한 자료에서 특정하지 못했습니다. 이 코드를 물리 START 버튼이 있다는 증거로 보거나, 반대로 미사용 코드라고 단정하지 않습니다. IO를 새로 설정하라는 안내도 아닙니다.
